# MY STYLE STUDIO — персональная капсула осень–зима 2026

Рабочий статический сайт для GitHub Pages. Не требует сборки, Node.js, базы данных или API-ключей.

## Запуск
1. Распакуйте ZIP.
2. Загрузите **содержимое** папки `MY-STYLE-STUDIO` в корень публичного репозитория GitHub.
3. Откройте Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Подождите публикации и откройте адрес GitHub Pages.
5. Для локального просмотра: `python -m http.server 8000` в папке проекта, затем http://localhost:8000. Прямой запуск `index.html` через `file://` не загрузит JSON в некоторых браузерах.

## Состав
- `index.html`, `style.css`, `app.js` — интерфейс и функции.
- `capsule.json` — 40 позиций из страниц 3–22 PDF; 61 страница оригинальных сочетаний из страниц 23–83.
- `assets/products` — фрагменты страниц с карточками товаров.
- `assets/looks` — страницы готовых сочетаний из PDF.
- `assets/model` — исходные фотографии модели.
- `assets/editorial-concepts.webp` — ранее созданная AI-концепция, **не подтверждённая примерка товаров**.

## Возможности
- Каталог вещей, категории, поиск, исходные ссылки на магазины.
- Просмотр всех 61 страниц образов, избранное.
- Персональный профиль, палитра и рекомендации по причёскам и макияжу.
- Конструктор сочетаний (выбор вещей, сохранение наборов). Не генерирует фото автоматически.
- Список желаний, учёт уже имеющихся вещей, ручное редактирование цен и суммы известных цен.
- Сохранение изменений в localStorage; экспорт и импорт JSON для переноса между устройствами.

## Достоверность
- Изображения товаров взяты из PDF, а не скачаны из магазинов. Ссылки извлечены из кликабельных областей PDF и могут устареть.
- **Цены не установлены**: изображения страниц содержат снимки цен, но они могут быть устаревшими; программа не выдаёт их за актуальные. Введите проверенную цену вручную.
- Список товаров и категории предварительные; названия уточняются по скриншотам. PDF не содержит надёжной машиночитаемой связки каждой вещи с каждым сочетанием.
- Страницы образов взяты из PDF; **это не фото девушки в конкретных товарах**. AI-генерация новых примерок не реализована, поскольку статический GitHub Pages не выполняет серверную генерацию.
- Стилистические советы являются рекомендациями, не измерениями фигуры или гарантией цветотипа.

## Конфиденциальность
**ВНИМАНИЕ:** Публичный GitHub Pages делает доступными исходные фотографии модели в `assets/model` и другие файлы репозитория. Загружайте только с разрешения изображённого человека. Для публичного релиза можно удалить папку `assets/model` и заменить фото нейтральными изображениями, однако ссылки на них тогда нужно исправить. Данные покупок и избранного хранятся локально в браузере, не отправляются на сервер.
