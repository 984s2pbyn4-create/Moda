## 3.9 — 3D конструктор
В конструкторе удалены исходные фотографии модели и фотокарточки вещей. Восстановлен вращаемый процедурный 3D-аватар с условной визуализацией выбранных категорий одежды. Точная подгонка одежды и портретное сходство пока не реализованы. Для 3D необходим доступ к esm.sh (Three.js); остальные разделы работают как раньше.
